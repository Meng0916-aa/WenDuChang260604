# Temporal Feature Analysis

This module supports the **Chapter-3 results analysis**: it turns thermal-cycle
curves into quantitative time-series features for comparing experiments
(including with- vs. without-magnetic-field).

## Input

Thermal-cycle CSVs produced by **script 04** (`src/preprocess/thermal_cycle.py`),
one per experiment, with columns:

```
frame, tmax, center_average, hot_zone_average
```

Default input directory: `data/processed/thermal_cycle` (config
`temporal_analysis.input_dir`).

## Output

- `results/tables/temporal_features.csv` — one row per experiment, with
  `<curve>_<feature>` columns for each of `tmax`, `center_average`,
  `hot_zone_average` (config `temporal_analysis.output_table`).
- `results/figures/temporal_feature_overview.png` / `.pdf` — bar charts of key
  features across experiments.
- `results/figures/temporal_curve_<id>.png` / `.pdf` — a few typical curve +
  dT/dt example plots (`temporal_analysis.max_examples_to_plot`).

## Time axis

The time axis is derived from the camera frame rate:
`t[i] = i / frame_rate_fps` seconds (config `temporal_analysis.frame_rate_fps`,
default 1000). This is independent of the dataset/training frame settings.

## Feature definitions (physical meaning)

| Feature | Meaning |
|---------|---------|
| `peak_temperature` | maximum temperature reached in the curve (°C) |
| `peak_time` | time at which the peak occurs (s) |
| `mean_temperature` / `std_temperature` / `min_temperature` | basic amplitude statistics (°C) |
| `max_heating_rate` | largest positive `dT/dt` — fastest heating (°C/s) |
| `max_cooling_rate` | most negative `dT/dt` — fastest cooling (°C/s, negative) |
| `mean_cooling_rate` | mean of all negative `dT/dt` values (°C/s) |
| `dwell_time_above_threshold` | total time the temperature stays ≥ `dwell_threshold` (s) — residence time in the hot regime |
| `temperature_auc` | area under the temperature–time curve (°C·s) — thermal exposure / heat input proxy |
| `fluctuation_index` | std of the high-frequency residual (raw − smoothed) normalized by mean temperature; ≥ 0 — measures noise/instability of the cycle |

`dT/dt` is computed with central differences (`numpy.gradient`) on the
optionally-smoothed curve (`temporal_analysis.smooth_window`, ≤ 1 disables
smoothing). Heating rate = positive `dT/dt`, cooling rate = negative `dT/dt`.

## SIMULATED data caveat

If `data/processed/thermal_cycle` contains `SIM_*.csv` files (generated by
script 05 as a fallback), script 09 prints a warning and tags all outputs
`SIMULATED`. **Simulated results only validate the code chain — they must not
be reported as experimental conclusions.** Archive `SIM_*.csv` manually before
running on real data (see `docs/after_experiment_checklist.md`).

## Running (after real data is imported)

Once scripts 02→04 have produced real thermal-cycle CSVs:

```powershell
conda activate pytorch
$env:KMP_DUPLICATE_LIB_OK="TRUE"
python scripts/09_analyze_temporal_features.py --config configs/default.yaml
```

Then inspect `results/tables/temporal_features.csv` and the figures under
`results/figures/`. Set `temporal_analysis.frame_rate_fps` to the real camera
frame rate so the time axis and all rate features (°C/s) are physically
correct.

## Notes

- `data/` and `results/` are git-ignored — never upload the CSVs/figures.
- This module is pure NumPy/Matplotlib; it does not touch the LSTM training
